## ✨ Features

- Create new tickets
- Edit existing tickets
- Delete tickets
- Search tickets
- Filter by status
- Dashboard statistics
- Dark / Light mode
- Local Storage support
- Responsive design

---

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage
- Font Awesome

---

## 📊 Dashboard

The dashboard displays:

- Total Tickets
- Open Tickets
- In Progress Tickets
- Closed Tickets

---

## 🔍 Search & Filter

Users can:

- Search by customer name
- Search by ticket title
- Filter tickets by status

## 💾 Data Persistence

All tickets are stored in LocalStorage.

Data remains available after page refresh.
